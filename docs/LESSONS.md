# 작업하며 얻은 지식 (사용자와의 대화에서 확정된 것)

새로 알게 된 것은 날짜와 함께 이 문서 맨 아래에 추가한다.

## 사용자 선호·판단 기준
- 회사 AI에는 **링크 하나만** 준다. 주소가 여러 개면 혼란스러워한다.
- 회사 AI는 외부 웹 검색이 안 된다. 아티팩트 페이지는 못 읽는다고 했다 → **gist의 텍스트 파일 링크**가 통했다. 아티팩트 페이지는 만들었다가 쓸모가 없어 사용자가 삭제했다.
- 사용자는 **완성된 결과를 먼저** 보고 싶어 한다. 표는 "한 줄 샘플"을 표 형태로 보여 달라고 했다(열이 길어도 가로 표).
- 데이터가 늘어나는 것은 괜찮다. **있는 정보는 다 넣는다.** 대표값·중간값은 "너무 임의"라고 거절당했다.
- 차량 가격은 목적이 아니다. 어떤 모델이 지금 혜택 중인지가 중요하다.
- 모델명 칸에 점검 결과·혜택 문구가 있으면 이상하다고 지적했고, 서비스 DB로서 **품질 점검 모듈을 항상** 넣으라고 했다.
- 틀리면 안 되는 데이터라 **검증 절차를 꼼꼼하게** 넣으라고 했다.
- 회사 AI가 보여준 표의 컬럼·내용이 달라서 불만이었다 → **표 작성 규칙과 정답 예시를 파일 안에 넣었다.**
- 주기 갱신은 **일요일 10시**(월요일 아님). 사용자는 출근하며 앱을 켠다. 모바일 앱에서는 예약 작업이 실행되지 않는다.

## 기간·값 해석 교훈 (2026-11-06)
- **목록에 적힌 기간은 게시 기간일 수 있다.** BYD 이벤트 목록의 `2026-10-25 ~`는 게시 시작이고, 행사 기간은 제목의 `(11.6-11.22)`였다. 상세 페이지·제목의 행사 기간을 쓰고 둘이 다르면 원문 대조 때 `기간` 표기를 함께 증거에 적는다.
- **옛 값이 틀려 있을 수 있다.** 폭스바겐 Golf R Roadshow는 '2월 시작'으로 적혀 있었는데 실제 특별 전시 기간은 10/24~11/26이었다. 이벤트는 매번 상세 페이지를 다시 연다.
- 같은 이벤트가 `related_events`(제목만)와 상세 수집에 둘 다 있으면 중복 행이 생기므로 한쪽(상세, `events_extra`)으로 옮긴다.
- 일부 브랜드는 이벤트 목록이 클릭 핸들러(기아)이거나 링크에 쿼리가 있어(제네시스) 도구 출력이 막힌다. 항목을 클릭해 상세로 들어가고 `location.pathname`으로 주소를 기록한다.

## 주간 자동 실행에서 배운 것 (2026-11-08)
- 첫 일요일 실행(11/8)은 점검 스크립트가 지목한 BMW·렉서스 2곳만 다시 읽어 **나머지 18곳의 주간 이벤트 변동을 놓칠 뻔했다.** 그래서 `data/watch_pages.json`(전 브랜드의 이벤트 목록·구매혜택 페이지 목록)을 만들고 `check_stale.py` 가 매번 이를 출력하게 했다. 주간 실행은 이 목록을 **전부** 읽는다.
- 실행 **후**에 `docs/` 를 고치면 gist 의 문서가 한 주 늦는다(11/8 15:07 gist 갱신 → 15:08 문서 수정). 문서는 `update_all.ps1` 실행 전에 고친다.
- 같은 달 안에서 끝난 이벤트(예: 11/8 종료)도 월 기준으로는 '기준월 해당'으로 남는다. AI용 파일 지침 7번에 "종료일이 생성일보다 앞서면 이미 끝난 것"을 넣었고, `check_stale.py` 의 [종료 임박/종료]로 확인해 기간을 정정한다.

## 원문 저장 요령 (2026-11-06, 구매혜택 페이지)
- 도구 출력은 한 번에 약 1,000자까지만 보이고 잘린다. 긴 본문은 `window.__t = text` 로 변수에 담고 `slice(0,950)`, `slice(950,1900)` … 로 **겹치지 않게** 나눠 읽는다(겹침을 주면 잘린 끝이 빠진다).
- **숨겨진 탭 내용**(기아 구매혜택은 EV/승용/RV 탭이 있고 화면에 숨은 것은 `innerText`에 없음)은 `document.body.textContent` 로 읽는다. 팝업 열기·상담 신청 같은 UI 버튼 문구는 지워도 되지만 그 사실을 증거의 `# method:` 에 적는다.
- **모델 탭**(KGM)은 탭 이름 버튼을 JS 루프로 하나씩 클릭해 각 탭의 '스페셜 혜택' 영역을 모아 한 번에 읽는다. **아코디언**(르노 '열기')은 `열기` 글자를 가진 요소를 모두 클릭한 뒤 `textContent` 로 읽는다.
- 목록에 항목별 링크가 다른데 한 페이지 주소로 뭉뚱그려 `link` 가 잘못된 경우가 있었다(아우디 모델별 페이지, 렉서스 ES 어메이징 스위치). `build_db.py` 일반 처리에서 항목의 `url` 또는 `source` 를 링크로 쓰게 고쳤다. 새 브랜드 JSON 을 만들 때 항목마다 `url`/`source` 를 적는다.
- 검증이 잡아낸 것: 렉서스 ES 항목이 monthly 페이지 링크를 달고 있었다(원문은 어메이징 스위치 페이지). 같은 주소 증거가 없으면 '증거 없음'이 되도록 해 둔 규칙 덕에 드러났다.

## 범위 지시와 외부 링크 (2026-11-06)
- **수집 범위는 '11월 구매 혜택(할인·시승·금융)'.** 인증중고차·보증연장·타이어 교체·멤버십 라운지·제휴(보험·여행·충전·증권) 같은 서비스성 항목은 정리하지 않는다. 이미 넣은 것은 `data/scope_exclude.json` 규칙으로 `benefits_excluded.*` 에 빼 두었다(삭제 아님). 새로 수집하다 범위 밖인 것을 발견하면 이 파일에 규칙을 추가한다.
- 목록 항목이 외부 링크(↗)이고 `href` 가 없을 때: `window.open = (u) => { location.href = String(u) }` 로 바꾼 뒤 항목을 클릭하면 같은 탭으로 이동한다. 주소를 직접 읽으면 쿼리스트링이라 도구가 막으므로(우회하지 않는다) 이동만 시킨다. 기아 카니발 보증연장은 `kia.autoew.co.kr`, 인증중고차는 `cpo.kia.com` 으로 연결됐다.
- 홈페이지 링크 추출로 안 나오는 메뉴(BMW '구매하기', 미니 '구매')는 **헤더 버튼을 클릭해 펼친 뒤 링크를 읽는다**(BMW는 `button` 클릭, 미니는 홈의 `a` 링크에 이미 있었음).

## 이벤트 페이지를 찾는 방법 (2026-11-06)
- 홈페이지 링크로 안 나오는 브랜드는 **도메인 한정 웹 검색 → 개별 페이지를 직접 열어 읽기** 순서가 잘 통했다(BMW). 검색 요약문 자체는 근거가 아니다.
- 주소를 추측해 `fetch`하면 단일 페이지 앱은 전부 200이라 속고, 아우디는 검색에 나온 이벤트 주소가 지금은 404였다. 반드시 화면/본문으로 확인한다.
- "캠페인 운영기간이 아닙니다" 같은 페이지는 종료된 이벤트이므로 넣지 않는다(BMW 네이버 특별 프로모션).

## 도구 함정
- **Python**: 항상 `python -I`. 콘솔에 한글을 찍으면 cp949 오류가 나므로 스크립트에서 `sys.stdout.reconfigure(encoding="utf-8")`, 긴 한글 출력은 파일로 쓰고 읽는다.
- **PowerShell 5.1**: 한글이 든 `.ps1` 은 **UTF-8 BOM**으로 저장해야 파싱된다. 네이티브 명령의 stderr(예: git의 CRLF 경고)가 `NativeCommandError` 로 보이지만 실패가 아니다. bash heredoc에 한글을 넣으면 깨지므로 파일 쓰기 도구를 쓴다.
- **gist raw 주소**는 CDN 캐시로 새 내용이 몇 분 늦게 보인다. 저장 여부는 `gh api gists/<id>` 의 `files.<이름>.size` 로 확인한다.
- **git push**가 서버 규칙(`commit_refs_rules`)으로 거절된 적이 있다(두 번). 다시 시도하면 성공했다. 반복 재시도는 하지 말고 사용자에게 알린다.
- **Claude in Chrome**:
  - `javascript_tool` 반환값에 **쿠키·쿼리스트링이 든 URL이 있으면 출력이 차단**된다. `href.split('?')[0]` 으로 자른 뒤 반환한다.
  - 로컬 수신 서버로 큰 데이터를 `fetch` 보내면 CDP가 멈춘다. 증거는 읽은 텍스트를 파일 쓰기 도구로 저장한다. 페이지가 파일을 내려받게 하는 방식은 다운로드 권한 규칙에 걸린다.
  - 단일 페이지 앱(렉서스 등)은 없는 주소도 200을 돌려준다. 상태코드로 존재 여부를 판단하지 말 것.
  - 이미지로 된 이벤트 본문은 `scroll` + `screenshot` 으로 읽는다. 스크롤 직후 같은 화면이 찍히면 한 번 더 스크롤한다.
- **아티팩트 삭제**는 이 환경에서 확인 절차가 없어 도구로 못 지운다. 사용자가 직접 지운다.

## 2026-11-08 주간 갱신에서 알게 된 것
- **BMW 금융 프로모션 7페이지**는 11/5 → 11/8 재확인해도 내용·숫자 전부 동일하게 "2026년 10월 1일~10월 31일" 기간으로 남아 있었다(11월분 갱신 안 됨). 10월 기간은 11월과 안 겹쳐 계속 `benefits_excluded` 처리. 매주 재확인은 필요하지만 변경이 없으면 숫자를 다시 베끼지 말고 `STALE_WARNING`만 재확인 날짜로 갱신하면 된다.
- **렉서스 `/2026-<month>-test-drive/` 패턴**: 11월 페이지(`/2026-nov-test-drive/`)를 열어도 200을 주지만 본문이 "요청하신 페이지를 찾을 수 없습니다"(SPA 404)였다. 상태코드로 판단하지 말고 `document.body.innerText`로 이 문구가 있는지 꼭 확인한다(LESSONS 기존 교훈과 동일 패턴, 11월에도 재확인됨).
- **`get_page_text`(article 추출) 도구는 탭·아코디언형 SPA에서 마지막으로 렌더된 카드만 가져올 수 있다.** 렉서스 이달의 구매혜택 페이지에서 `get_page_text`는 LS 500h 카드 하나만 반환했지만, 같은 페이지에서 `javascript_tool`로 `document.body.innerText`를 직접 읽으면 NX~LS 전체가 나왔다. 페이지가 리스트형이면 `get_page_text`보다 `javascript_tool` innerText를 우선한다.
- 렉서스 ES 어메이징 스위치(잔존가치 보장 할부) 페이지는 "월 납입금 예시"에 **그 달의 금융조건**(금리 5.80%, 월 납입금 42.5만원 등, "2026년 11월 금융조건 기준"이라고 명시)이 들어 있다. 이 예시 숫자는 매달 바뀔 수 있으니 재수집 때마다 다시 읽는다.
