# 작업 요약 (2026-11-06 기준)

사용자(허호필)와 Claude가 함께 만든 **국내 신차 월별 구매 혜택 DB**의 진행 상황 요약입니다. 처음 읽는 사람/AI는 이 문서 → `docs/HANDOFF.md` 순서로 보세요.

## 1. 무엇을 만들었나
- **목적**: 회사 AI(외부 웹 검색 불가)가 파일만 읽고 "이번 달 어느 모델이 어떤 혜택(할인·시승·금융)을 받나"에 답할 수 있게 하는 DB. 가격은 참고 정보.
- **전달 방식**: 링크 하나(gist `car_db_for_ai.md`). 같은 gist 에 `testdrive.json`, `offers.jsonl`, 수집 가이드 4종, 누적 이력 `benefits_history.csv` 가 함께 있음. 전체 프로젝트는 GitHub `period317/car-db`(공개).
- **현재 규모(2026-11-06)**: 월별 혜택 **172건 / 20개 브랜드**, 시승 DB 35개 브랜드(온라인 신청 가능 25곳, 시승 이벤트 있는 곳 9곳: 현대·KGM·BMW·미니·르노·폭스바겐·볼보·토요타·BYD). 원문 증거 77개 파일. 할인구분: 정액 80 · 정률 10 · 정액+정률 5 · 금융 조건 37 · 할인 없음 40.

## 2. 데이터 구조 (사용자 요구로 정한 것)
- 혜택 한 건 = **기준월 / 모델·세부모델·연식 / 이벤트명 / 유형(할인·금융·증정·시승혜택·이벤트) / 할인구분·할인금액(만원)·할인율(%) / 조건 / 증정·경품 / 기간 / 링크 / 검증**.
- 차량 모델명과 이벤트명을 **분리**했고(모델 칸에 혜택·연식이 섞이면 ERROR), 할인 금액은 **별도 숫자 컬럼**. 선택지가 여러 개면 가장 큰 값 + 전체 목록(`discount_options`). 대표값·중간값은 쓰지 않음.
- AI용 파일 맨 앞에 **표 작성 규칙과 정답 예시**(19열 표)를 넣어 다른 AI가 같은 표를 만들게 함. 맨 끝에 수집 가이드 부록.

## 3. 수집 범위·정책 (사용자 지시)
- **11월 구매 혜택(할인·시승·금융)만.** 중고차·보증연장·정비·멤버십·제휴(보험·여행·충전·증권) 서비스는 정리하지 않음(`data/scope_exclude.json` 규칙으로 제외, 26건 보관).
- **대상 월과 기간이 겹치지 않는 혜택은 표에서 제외**(BMW 10월 금융 프로모션 15건, 렉서스 가을 시승회 1건 → `benefits_excluded.*` 보관, 누적 이력에는 기록).
- **공식 홈페이지·공식 금융사에서 직접 열어 읽은 것만.** 검색 결과 요약·기사만 있는 것은 넣지 않음. 읽기 전용(로그인·신청 폼 제출·개인정보 입력 금지), 쿠키는 필수만.

## 4. 검증 체계 ("틀리면 안 된다")
1. 읽은 공식 페이지 본문을 `data/evidence/<브랜드>/` 에 저장(이미지 페이지는 스크린샷 육안으로 옮겨 적고 그렇게 표시).
2. `verify_evidence.py` 가 항목의 금액·%·개월·인원·모델명·기간이 **같은 주소의 원문**에 있는지 자동 대조. 원문에 없으면 **게시 중단(ERROR)**. 표기만 다른 경우에만 이유를 적은 예외(`verify_ack.json`).
3. `quality_check.py` 가 모델/이벤트명 혼합, 할인금액 누락, 만료·중복, 이전 대비 감소 등을 점검. ERROR 0 이어야 GitHub·gist 게시.
4. 결과: **172건 전부 같은 페이지 원문으로 대조 완료**, 품질 ERROR 0. 한계: DB 값이 우리가 읽은 원문과 같은지만 확인하며, 공식 페이지 자체의 오류는 못 잡음.
- 검증이 실제로 잡아낸 것: 현대 직트럭 프로모션 시작일, 폭스바겐 Golf R 로드쇼 기간(2월 시작이 아니라 10/24~11/26), 아우디·렉서스 링크 오류, 쉐보레 재고할인 표기 차이 등.

## 6. 자동 갱신과 누적(덮어쓰지 않음)
- **자동 갱신**: Claude 예약 작업 `car-db-weekly-refresh`(신차 DB 주간 갱신)가 **매주 일요일 10시경** `docs/REFRESH_PLAYBOOK.md` 대로 공식 사이트를 다시 읽고 `scripts/update_all.ps1` 로 커밋·푸시·gist 갱신. (PC와 Claude 데스크톱 앱이 켜져 있어야 함)
- **누적 이력**: 갱신 때마다 `data/history/` 에 새 항목·변경·종료만 **덧붙임**(지우거나 덮어쓰지 않음). `benefits_history.jsonl`(원본 로그), `benefits_history.csv`(표), `snapshots/`(날짜별 전체 사본). 과거 월은 `scripts/query_history.py --ym 2026-10 --brand BMW` 로 조회, 회사 AI는 gist 의 `benefits_history.csv` 로 조회. 월 판단 규칙은 `COLLECTION_GUIDE.md` 6.5절.
