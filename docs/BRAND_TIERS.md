# 주요 브랜드(main) / 예외(minor) 기준

기준 데이터: `data/brand_tiers.json` (2026-10 월 판매량). 출처: 국산 = KAMA 집계 보도(오토트리뷴·라이센스뉴스·다나와, 현대는 제네시스 제외 43,100대), 수입 = KAIDA 10월 신규등록(카가이·M포스트·다나와). 기사마다 수치가 조금 다르므로 대략값이다.

## 규칙
1. **최근 월 판매량 400대 이상 = main(주요)**, 미만 = minor(예외).
2. 400대인 이유: 월 461대(아우디)와 244대(폴스타) 사이에 큰 간격이 있어 경계가 안정적이다.
3. **분기마다(1·4·7·10월) 직전 3개월 평균으로 재판정**한다. main이 minor로 내려가려면 2분기 연속 400대 미만이어야 한다(경계 브랜드가 오르내리지 않도록).
4. minor 브랜드는 수집을 중단하지 않지만 **품질 점검·주간 갱신에서 후순위**로 둔다. 데이터가 없어도 오류로 보지 않는다.

사용자가 지정한 17개(현대·기아·제네시스·르노·쉐보레·KGM·테슬라·BYD·벤츠·BMW·포르쉐·아우디·볼보·토요타·렉서스·미니) 중 **폭스바겐이 빠져 있었는데 판매량이 아우디(461)·포르쉐(768)·MINI(704)보다 많아(950) 이 기준으로는 main이다.** 지정 목록과 이 기준은 그 하나만 다르다.

## 현재 DB 커버리지 점검 결과 (2026-11-10 보강 후, 혜택 225행)
- **테슬라**: 0행 → 2행. 공식 사이트에서 읽히는 것만 반영(제휴 금융사 우리금융캐피탈 리스·삼성카드 할부 안내, 시승 신청). 보도된 11월 자체 보조금(모델 Y 215만원 등)은 공식 페이지에 텍스트가 없어 제외(주문 단계에서만 표시될 가능성).
- **BYD 금융**: 공식 홈페이지에 금융·할부 안내가 없음(이벤트 페이지만 있고 이미 수집). 전속 금융사는 하나캐피탈로 바뀐 것으로 보도(이벤트 목록 비어 있음). 보조금·할부는 딜러·보도 기준이라 미수집.
- **MINI**: BMW파이낸셜 2페이지에서 MINI 구매 혜택(리스료 최대 3개월 지원, 2026-11-01~11-30) 추가. BMW도 Next Drive 프로모션·재구매 프로모션(최대 150만원 상당) 추가.
- **시승 0행 브랜드(기아·제네시스·렉서스·벤츠·포르쉐·쉐보레)**: 재확인 결과 `testdrive.json`에 이미 브랜드별로 시승 신청 방법과 이벤트 유무(has_event)가 정리돼 있고, 이들은 11월 시승 '이벤트'가 없거나(제네시스는 방문 프로모션만, 벤츠 AMG 행사는 시승 이벤트 아님, 렉서스 시승회는 11/3 종료) 온라인 시승 신청이 없는 곳(쉐보레·포르쉐)이다. 즉 benefits 표의 시승 0행은 누락이 아니라 '이벤트 없음'이다.
- **포르쉐 금융 1행**: 포르쉐 FS 사이트에 프로모션 메뉴 없음 → 추가 불가. **쉐보레**: 금융 조건이 제조사 이벤트(할부 36개월 5.0%·60개월 5.5%)에 들어 있고 한국GM 전속 금융사가 없음.

## 운영 방침
- 주간 갱신 점검 순서: main 17개 먼저 → minor는 여유가 있을 때.
- 새 브랜드가 분기 재판정에서 400대를 넘으면 main으로 올리고 이 문서와 `brand_tiers.json`을 갱신한다.
