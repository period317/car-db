## 판단 규칙
- 제조사 사이트에 이미 적힌 금융 조건(예: 쉐보레 36개월 5.0%)은 제조사 행으로 두고, 금융사 사이트에서 새로 확인되는 것만 금융사 행으로 추가한다.
- 기사 근거는 최신 여부가 불확실하므로 금융사 공식 사이트에서 11월 프로모션이 읽힐 때만 데이터에 넣는다.

## 2026-11-10 조사 결과 요약
- 금융사 사이트에서 11월 금융 혜택이 읽힌 곳: 현대캐피탈, BMW파이낸셜, 폭스바겐파이낸셜(제목·기간만).
- 읽었지만 11월 구매 혜택이 없었던 곳: 아우디 FS(재구매 이벤트만), 벤츠 FS, 토요타 FS, 렉서스 FS, 포르쉐 FS.
- 아직 못 읽은 곳(사이트 주소부터 확인 필요): 모빌라이즈 FS, 폴스타(KB캐피탈, 10월 행사엔 우리금융캐피탈 장기 할부 언급), 지프·푸조(하나캐피탈 제휴, 2026-09 기사), BYD(우리금융캐피탈), 볼보 승용, JLR, 포드·링컨·혼다. 제조사 사이트의 11월 금융 조건은 제조사 행에 이미 들어 있는 경우가 많다.
